Start with the [project README](../README.md) for installation and data preparation.

```powershell
python run_console.py --host 127.0.0.1 --port 8770
```

Open Run Console at `/`, Debug at `/debug`, and a generated Final Viewer from
the run history. Data and runtime directories are created or supplied locally;
none are populated in this repository.
