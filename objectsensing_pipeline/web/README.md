# Browser interfaces

[Project README](../../README.md) | [Usage guide](../docs/USAGE.md)

- `run-console/`: local run orchestration and live/replayed events, served at `/`.
- `debug/`: instrumented scientific stages, served at `/debug`.
- `viewer/`: Final Viewer styles; HTML is generated by `timeline_viewer.py`.
- `shared/`: common controls, timeline interactions and Three.js rendering.

Assets are registered in `web_assets.py`. Local pages use `vendor/` dependencies;
generated Final Viewer files embed them. There is no frontend build step.
Element IDs and API keys remain stable while visible labels and help are English.
The annotation interface and comparison galleries are excluded from this handoff.
