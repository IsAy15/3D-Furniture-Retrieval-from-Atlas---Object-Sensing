# Architecture and project structure

[Documentation index](README.md)

The scientific modules remain flat to preserve established imports. Run commands
from `objectsensing_pipeline/`; this repository is not an installable pip package.

| Module | Responsibility |
| --- | --- |
| `cli.py`, `config.py` | Commands and scientific configuration |
| `runtime_paths.py` | Portable runtime/data roots and environment overrides |
| `sdf_fusion.py`, `geometry.py` | RGB-D input, TSDF, visibility and scene geometry |
| `keypoints.py`, `wall_keypoints.py`, `keypoint_quality.py` | Keypoint detection and scan-specific filtering |
| `keypoint_groups.py` | Group surface/keypoint evidence into object proposals |
| `descriptors.py`, `primitives.py` | Local UDF/occupancy descriptors and primitive support |
| `database.py`, `db_store.py`, `shapenet_loader.py` | CAD preprocessing, storage and loading |
| `candidate_index.py`, `local_preselection.py` | Broad index, local proposals and reranking |
| `matching.py`, `constellations.py`, `transforms.py` | Correspondences, RANSAC and ground transforms |
| `verify.py`, `pipeline.py`, `progressive.py` | Pose checks, selection, orchestration and caches |
| `run_console.py`, `live_events.py` | Local HTTP control, jobs and JSONL event streams |
| `debug_visualizer.py`, `debug_retrieval.py` | Instrumented stages and independent artifacts |
| `viz.py`, `timeline_viewer.py`, `io_aln.py` | PLY, standalone HTML and ALN exports |
| `web_assets.py`, `web/`, `ui_help_en.py` | Three UI workflows, shared rendering and English help |

`tools/build_local_candidate_index.py` builds the compact UDF supplement.
Other included tools support repeatable diagnostics and documentation checks.
`dev/run_debug_chain.py` provides a headless debug-stage chain. Tests use synthetic
inputs; excluded manual experiments depended on author-specific files.

Browser assets live under `web/run-console`, `web/debug`, `web/viewer` and
`web/shared`. The Final Viewer HTML template is generated by `timeline_viewer.py`.
`vendor/` holds browser dependencies and licenses. No annotator assets are included.

Runtime directories (`scenes`, `db_dir`, `work`) are external inputs or generated
state. They are intentionally absent from the source repository. Database model paths
refer to external source geometry. Worker subprocesses use the current Python
interpreter, so launch the server from the environment containing the scientific dependencies.
